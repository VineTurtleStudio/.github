## 🇨🇳 简体中文

**藤栖龟舍** 是一个**多人协作的小型工作室**，做「本地优先」的桌面工具、静态站点和自动化脚本。

日常主力是 **Tauri 2 + Rust + React**：窗口要小、启动要快、数据不出本机。目前大部分仓库由 [@VineTurtle](https://github.com/VineTurtle) 代为管理，其他成员在这里建分支、提 PR、共同维护；组织空间也用来放需要独立仓库的项目（公开发布版、协作仓库、静态站点）。

### 项目

| 项目 | 一句话 | 技术栈 |
|---|---|---|
| **[VineHub](https://github.com/VineTurtleStudio/VineHub)** | 文件类工具的统一主面板：单窗口 + iframe 面板 + sidecar 插件 | Tauri 2 + React |
| **[VinePalmaPet](https://github.com/VineTurtleStudio/VinePalmaPet)** | 2D 桌面宠物：帧动画、像素级点击穿透、沙箱插件 | Tauri 2 + React |
| **[VinePalmaLeaf](https://github.com/VineTurtleStudio/VinePalmaLeaf)** | 本地优先的电子书阅读器（EPUB / PDF / TXT） | Tauri 2 + React |
| **[VinePalmaFlow](https://github.com/VineTurtleStudio/VinePalmaFlow)** | 项目管理：数据是 Markdown / YAML，局域网加密配对同步 | Tauri 2 + React |
| **[VinePalmaUninstaller](https://github.com/VineTurtleStudio/VinePalmaUninstaller)** | Linux 应用卸载与残留清理（apt / flatpak / snap / appimage / docker） | Tauri 2 + Rust |
| **[VinePalma-Player](https://github.com/VineTurtleStudio/VinePalma-Player)** | 基于 FFmpeg 的桌面媒体播放器 | Tauri 2 + Rust |
| **[GrapeLeafi-QQbot](https://github.com/VineTurtleStudio/GrapeLeafi-QQbot)** | 本机自建 QQ 机器人框架（NapCatQQ + Node.js，内置防风控） | Node.js |
| **[VineTurtleStudio](https://github.com/VineTurtleStudio/VineTurtleStudio)** | 工作室官网（纯静态，无构建步骤） | HTML / CSS / JS |

> 成员的早期个人项目与实验性代码仍在各自的个人账号下，例如 [@VineTurtle](https://github.com/VineTurtle)。

### 一起做

- 想改哪个项目就在哪个仓库开 issue，说明场景和期望
- 提交代码请走 **分支 + Pull Request**，不要直接推 `main`
- 每个仓库的 README 都写了依赖、启动命令和目录结构，先照着跑起来

## 🇬🇧 English

**VineTurtleStudio** is a **small collaborative studio** building **local-first** desktop tools, static sites and automation scripts.

The daily stack is **Tauri 2 + Rust + React**: small windows, fast startup, and your data never leaves your machine. Most repositories are currently managed by [@VineTurtle](https://github.com/VineTurtle); the rest of the team works here through branches and pull requests. The organization also hosts projects that need their own space (public releases, shared repos, static sites).

### Projects

| Project | What it is | Stack |
|---|---|---|
| **[VineHub](https://github.com/VineTurtleStudio/VineHub)** | host panel for the file tools: single window, iframe panels, sidecar plugins | Tauri 2 + React |
| **[VinePalmaPet](https://github.com/VineTurtleStudio/VinePalmaPet)** | 2D desktop pet: frame animation, pixel-level click-through, sandboxed plugins | Tauri 2 + React |
| **[VinePalmaLeaf](https://github.com/VineTurtleStudio/VinePalmaLeaf)** | local-first ebook reader (EPUB / PDF / TXT) | Tauri 2 + React |
| **[VinePalmaFlow](https://github.com/VineTurtleStudio/VinePalmaFlow)** | project management on Markdown / YAML with encrypted LAN pairing and sync | Tauri 2 + React |
| **[VinePalmaUninstaller](https://github.com/VineTurtleStudio/VinePalmaUninstaller)** | Linux uninstaller and leftover cleanup (apt / flatpak / snap / appimage / docker) | Tauri 2 + Rust |
| **[VinePalma-Player](https://github.com/VineTurtleStudio/VinePalma-Player)** | FFmpeg-based desktop media player | Tauri 2 + Rust |
| **[GrapeLeafi-QQbot](https://github.com/VineTurtleStudio/GrapeLeafi-QQbot)** | self-hosted QQ bot framework (NapCatQQ + Node.js, built-in anti-risk-control) | Node.js |
| **[VineTurtleStudio](https://github.com/VineTurtleStudio/VineTurtleStudio)** | studio website (plain static, no build step) | HTML / CSS / JS |

> Early personal projects and experiments stay on each member's own account, for example [@VineTurtle](https://github.com/VineTurtle).

### Working together

- Open an issue in the relevant repo and describe the use case and what you expect
- Send changes as **branch + pull request**; please don't push to `main` directly
- Every repo's README covers dependencies, start commands and layout — get it running first

## 🇯🇵 日本語

主力は **Tauri 2 + Rust + React**：小さいウィンドウ、速い起動、データはマシンの外に出ません。現在ほとんどのリポジトリは [@VineTurtle](https://github.com/VineTurtle) が管理しており、他のメンバーはブランチと Pull Request で参加しています。独立したリポジトリが必要なプロジェクト（公開版・共同リポジトリ・静的サイト）もこの Organization に置いています。
